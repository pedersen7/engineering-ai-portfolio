# Project Presentation

This presentation provides a visual overview of the **Caltrans Utility AI Assistant**, an independently developed engineering AI prototype exploring the application of Artificial Intelligence to transportation and utility engineering.

The presentation describes the project's:

* Engineering motivation and objectives
* Computer vision component for infrastructure asset detection
* Retrieval-Augmented Generation (RAG) component for engineering knowledge retrieval
* Integration of engineering context and workflow
* Development and evaluation approach
* Lessons learned from both computer vision and RAG development
* Potential future integration of field information, engineering knowledge, and AI-assisted workflows
